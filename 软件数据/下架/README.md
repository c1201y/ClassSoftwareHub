# 下架软件

本目录**不被任何代码读取**。站点只扫 `软件数据/apps/*.json`（`src/gallery/data/index.ts` 的 `import.meta.glob`），
桌面端同步后也只读 `apps/`（`Core/ContentStore.cs`），所以把文件移到这里 = 从清单消失。

不直接删，是为了留下原文件与原因，日后想恢复搬回 `apps/` 即可。

---

## shasherayxingz.json —— SHasher（2026-11-01 下架）

**原因**：没有任何授权凭据。

- 无官网、无 GitHub 仓库、无许可声明；
- 安装包此前由本站对象存储对外分发（`oss://releases/2026/10/...`），属于再分发；
- 投稿记录里查不到投稿人信息（`submissions/` 无对应条目），无法补齐授权来源。

**处置**：条目下架，OSS 上的 3 个文件（x64 / x86 / 哈希值）停止引用。

**恢复条件**：拿到作者明确的再分发授权，或改为只放作者自己的发布页链接，即可搬回 `apps/`，
补上 `author` 与 `license` 两个字段。
