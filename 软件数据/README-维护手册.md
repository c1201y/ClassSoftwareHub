# 📦 软件数据维护手册

> 本文件夹 = 网站的「软件数据」区：**每个软件一个文件**，互不干扰。
> 分类 → `categories.json`；软件 → `apps/` 文件夹；页面代码完全不用碰。

---

## 一、添加一个新软件（3 步，1 分钟）

1. 打开 `apps/` 文件夹，**复制 `_模板.json`**，粘贴后改名成 `软件英文id.json`
   （例如添加「记事本」就命名 `notepad.json`，名字随便，只要英文小写+短横线，别用中文和符号）
2. 打开这个新文件，把模板里每个字段的值改成新软件的信息
   （每个字段旁边都写了该填什么）
3. 保存。开发预览（`npm run dev`）下浏览器**自动刷新**就能看到；
   正式发布前跑一下 `npm run build`（或 `npm run build:single` 出单文件版）

> 新软件会显示在最后面。想插到中间就把 `sort` 数字改成想要的位置
> （数字越小越靠前，例如想排第 3 名就填 2；0 是最前面）。

---

## 二、修改 / 删除软件

- **改信息**：直接打开 `apps/<id>.json` 编辑，保存即生效。
- **删除软件**：直接把那个 `.json` 文件删掉。

---

## 三、字段说明（跟原版 HTML 里的注释一一对应）

| 字段 | 含义 | 注意 |
|---|---|---|
| `id` | 唯一英文标识 | **不能重复**；网址就是 `#/download/<id>`；只允许英文小写、数字、短横线。**别带 `?` `&` `=` 等符号** |
| `name` | 软件名称 | 随便 |
| `icon` | 图标图片链接 | 建议正方形（256×256）；留空则显示空白占位 |
| `category` | 所属分类 | 必须是 `categories.json` 里的 key：`system`(系统工具) / `schedule`(教学软件) / `teaching`(教学辅助) / `other`(其他工具) |
| `tagline` | 一句话简介 | 首页卡片上显示 |
| `description` | 详细介绍 | 详情页显示 |
| `version` | 版本号 |  |
| `size` | 软件体积 | 同上 |
| `system` | 系统限制 | 如 `Windows 10/11（x86 / x64 / ARM64）、macOS、Linux` |
| `website` | 官方网站 |  |
| `github` | GitHub 仓库 |  |
| `notice` | 更新提示（可选） | 更新频繁、直链容易失效的软件写一句话。会在详情页「下载」上方显示一条蓝色提示条。不要就整行删掉 |
| `store` | 应用商店链接（可选） | 填商店网页地址（如 `https://apps.microsoft.com/detail/xxxx`）。详情页会多出一个「使用 Microsoft Store 下载」入口。不要就整行删掉 |
| `downloads` | 下载项数组 | 见下方模板；一个平台/架构一项 |
| `sort` | 显示顺序 | 数字小的靠前；一般不用动 |
| `维护备注` | 你自己的备忘 | 网页不显示，放心写 |

`downloads` 里每一项长这样（注意是**英文逗号**分隔，最后一项后面没有逗号）：

```json
{
  "platform": "Windows x64 安装版",
  "note": "官方安装包，GitHub 链接有时不稳定",
  "size": "373 KB",
  "url": "https://github.com/xxx/xxx/releases/download/xxx.exe"
}
```

- `url` 必须是**文件直链**（.exe / .zip / .msi…），点了**直接开始下载**，不要填官网下载页地址。
  没有直链就整项删掉或先不填；也可以把官网下载页当作一项写进来，把 `size` 写成「网页」并在 `note` 里说明。
- 多个下载项就在数组里用 `{ ... },` 逗号分隔。

### 什么时候用 `notice` / `store`？

- **更新特别频繁的软件**（如 PowerToys、ToDesk、驱动总裁……）：直链写死了很快就失效。
  两种做法：
  1. 只填**官网「始终最新」的链接**（很多官网有这样的固定地址），或在 `downloads` 里放官网下载页；
  2. 写上 `notice` 提醒大家「去官网 / 应用商店拿最新版」。
- **应用商店里有官方版的软件**（PowerToys、VLC、GeoGebra、UU远程、图吧工具箱…）：
  填上 `store`，详情页就会出现「使用 Microsoft Store 下载」按钮——商店版**自动更新**，
  最省心，等于把「跟版本」这件事交给商店。
  > 💡 **不用非得写 `store`**：只要 `downloads` 里有一项 `url` 是指向 `apps.microsoft.com` 的商店页
  > （老软件就是这么写的），详情页会**自动**把它认出来、显示成同一张商店卡片，不会再多出一行普通下载项。
  > 所以两种写法都行，看你顺手。

---

## 四、改分类（一般不碰）

`categories.json` 有 4 个分类（key/名称/图标）。改名直接改 `name`。
图标 `icon` 是字体符号代码（形如 `\uE90F` 的转义），想换需要 Fluent 图标表，**建议别乱改**。

---

## 五、JSON 语法小抄（改坏了不会白屏，放心试）

- 每行格式：`"字段名": 值` —— 冒号、引号、逗号都要是**英文**。
- 字符串（文字、网址）用**英文双引号**包住。
- 最后一行的值后面**不要**加逗号。
- 不确定时：复制 `_模板.json` 改，别从空白开始手打。

**写坏了会怎样？** 这个网站有兜底：哪个文件坏，就只跳过哪个文件，其余照常显示；页面**顶部会出现一条红底提示**，写明：
「有 N 个数据文件没读进来」+ 每个坏文件的名字 + 大概错在第几行 + 原因
（鼠标悬停在红条条目上还能看到浏览器原始报错）。
改完保存刷新就能看到红条，照着改对后红条自动消失 —— 不会像以前那样整个站打不开。
