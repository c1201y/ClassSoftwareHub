# 回声洞

QQ 群里那些让人笑出声的沙雕发言。**一条一个文件**，全部放在 `messages/` 目录下。

## 加一条发言

1. 在 `messages/` 下新建 `messageN.json`，N 取当前最大编号 + 1
   （已有 `message1` ~ `message7`，就新建 `message8.json`）
2. 文件内容只写一句：

   ```json
   { "text": "要收录的发言" }
   ```

3. 提交分支 → 开一个 PR

> 编号不要重复、不要跳号复用；网站、桌面应用、CSHcontroller 都按文件名里的数字排序。

## 为什么改成一条一个文件

- 加一条 = 新增一个文件，删一条 = 删一个文件。改动面小，多人同时投稿也不会撞车。
- 网页端、桌面应用、CSHcontroller 控制台读的是同一套目录，格式统一。

## 怎么查内容

在 GitHub 网页上只能看到 `message1`、`message2` 这样的文件名，看不到写了什么。
要查看或搜索具体内容，用 **CSHcontroller 控制台的「回声洞」页**——那里有列表和搜索框。
